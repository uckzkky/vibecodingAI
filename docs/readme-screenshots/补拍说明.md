# 答辩用宽屏截图（可选）

README 已包含分块截图。如需**左侧内容区与右侧「检索轨迹」同屏**的宽屏展示图，可按下列步骤补拍。

## 操作步骤

1. 将浏览器窗口宽度设为 **至少 1280 像素**（推荐 1440×900）。  
2. 启动项目并打开 http://127.0.0.1:8765 ，输入 `lufive的《2008》`，等待检索完成。  
3. 适当滚动页面，使**左侧**可见「词云」或「情感对比」，**右侧**可见多条带时间的轨迹记录。  
4. 截屏并保存为本目录下的 **`06-layout-wide.png`**。  
5. 如需写入 README，可增加一行：

```markdown
![宽屏：主内容区与检索轨迹同屏](docs/readme-screenshots/06-layout-wide.png)
```

## 建议在图上标注的区域

| 编号 | 对应功能 |
|------|----------|
| 1 | 查询框与「开始检索」 |
| 2 | 三个概览数字（平台 / 词 / 最高表态） |
| 3 | 各平台词云 |
| 4 | 情感对比 |
| 5 | AI 乐评 |
| 6 | 检索轨迹（CALL / OBS / LLM） |

用系统截图、Snipaste 或 PPT 标号即可，无需专业修图。
